# منصة الامتحانات التعليمية

واجهة Front-End كاملة باستخدام:
- HTML
- CSS
- JavaScript Vanilla
- تصميم RTL عربي ومتجاوب
- الشعار المرفق داخل `assets/logo.png`

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## أين تعدل المحتوى؟
داخل `app.js`:
1. `grades` لتعديل الصفوف الدراسية.
2. `exams` لإضافة/تعديل الامتحانات.
3. `questionBank` لإضافة الأسئلة والإجابات الصحيحة.

## المزايا الحالية
- اختيار الصف.
- 3 مواد: اللغة العربية، اللغة الألمانية، الدراسات الاجتماعية.
- بطاقات امتحانات.
- مؤقت لكل امتحان.
- شريط تقدم.
- اختيار وحفظ الإجابات أثناء الامتحان.
- تسليم تلقائي عند انتهاء الوقت.
- تصحيح فوري وحساب النسبة.
- حفظ سجل النتائج واسم الطالب في LocalStorage.
- Dark Mode.
- تصميم متجاوب للموبايل والكمبيوتر.
